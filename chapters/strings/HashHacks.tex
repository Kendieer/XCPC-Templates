\section{Thue–Morse 序列}

用于构造字符串哈希反例，hack 自然溢出（$2^{64}$）或 $2^x$ 取模的字符串哈希，与基数无关。

\texttt{ThueMorse(MOD)} 返回长度 $2^p$ 的串；\texttt{MOD} 需为 $0$ 或 $2$ 的幂（否则断言失败），冲突长度为 $2^{p-1}$。

\begin{lstlisting}
// 用于 hack 自然溢出或者 2^x 作为模数
std::string ThueMorse(unsigned long long MOD = 0){
    assert(__builtin_popcountll(MOD) == 1 || MOD == 0);
    int p = 12;
    int len = 1 << p;// 冲突长度为 (2^(p-1))
    std::string str;
    for (int i = 0;i < len;i ++) str += 'a'+(__builtin_popcount(i)&1);
    return str;
}
\end{lstlisting}
